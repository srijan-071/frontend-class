# Contributing

Thanks for helping improve this collection of frontend exercises.

## Before opening a change

- Keep examples focused on the concept they demonstrate.
- Prefer semantic HTML and accessible controls.
- Keep CSS readable and avoid unnecessary dependencies.
- Test changes in a current browser before submitting them.
- Do not commit generated build output or editor files.

## Pull requests

Describe what changed and why. For UI changes, include a screenshot when it helps reviewers understand the result.
